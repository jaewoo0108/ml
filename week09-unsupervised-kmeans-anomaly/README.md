## 2. K-means 알고리즘

K개의 클러스터 중심점을 찾기 위해, 배정된 데이터들의 평균 위치로 중심점을 계속 이동시키는 알고리즘. 클러스터 배정과 중심점 이동이라는 2단계를 반복적으로 수행.

### <0번째 단계: 초기화>

이미 존재하는 실제 훈련 데이터들 중에서 무작위로 k개를 뽑아 그 데이터들의 좌표를 맨 처음 중심점의 위치로 설정.

→ 초기에 무작위로 설정되는 중심점의 위치에 따라 K-means의 최종 클러스터링 결과가 달라질 수 있기 때문에 Random Initialization 적용.

### <1번째 단계: 클러스터 배정>

각각의 데이터(점)가 어느 중심점에 가까운지에 따라 모든 데이터들을 해당하는 클러스터 중심점(Centroid)에 배정한다.

→ 클러스터 중심점 좌표는 고정한 채, 클러스터의 번호 ($c^{(1)} \sim c^{(m)}$)만을 업데이트.

### <2번째 단계: 중심점 이동>

각 클러스터 중심점을 자신에게 배정된 모든 데이터들의 평균 위치로 이동시킨다.

→ 클러스터의 번호는 고정한 채, 중심점 좌표 ($\mu_1 \sim \mu_K$)만을 업데이트.

## 3. 수학적인 수식으로 표현한 K-means

### <1단계 클러스터 배정>

$$c^{(i)} = \arg\min_k ||x^{(i)} - \mu_k||^2$$

- $x^{(i)}$: i번째 훈련 데이터 포인트 (우리가 분류해야 할 대상)
- $\mu_k$: k번째 클러스터의 중심점(Centroid) 좌표
- $c^{(i)}$: 데이터 포인트 $x^{(i)}$가 배정된 클러스터의 번호

$$\text{Distance} = \sqrt{(x_1 - \mu_1)^2 + (x_2 - \mu_2)^2 + \dots}$$

$||x^{(i)} - \mu_k||$ → 데이터 포인트 $x^{(i)}$와 중심점 $\mu_k$ 사이의 직선 거리를 뜻한다. 피타고라스 정리를 사용하여 계산. 제곱근 연산은 비용이 많이 들고, 양수를 제곱해도 비교값은 변하지 않기에 노름의 제곱으로 구함.

### <2단계 클러스터 중심점 이동>

$$\mu_k = \frac{1}{|S_k|} \sum_{i \in S_k} x^{(i)}$$

$S_k$: k번 클러스터에 배정된 데이터 포인트들의 집합.

k번 클러스터에 배정된 모든 점들을 살펴보고 첫 번째 특성 $x_1$의 값들을 모아 평균을 내고, 두 번째 특성 $x_2$의 평균값도 계산하는 방식으로 중심점이 이동할 평균을 구한다.

(클러스터 중심점인 $\mu$ 역시 훈련 데이터가 가지는 특성의 개수와 동일한 개수($n$개의 특성이 있다면 $n$개의 숫자)가 들어있는 벡터가 된다.)

### <K-means의 cost function - Distortion Function>

$$J = \frac{1}{m} \sum_{i=1}^{m} ||x_i - \mu_{c_i}||^2$$

$\mu_{c^{(i)}}$: i번째 데이터가 배정된 클러스터 중심점의 실제 위치 좌표.

모든 훈련 데이터 포인트와 각각이 배정된 클러스터 중심점 사이의 평균 제곱 거리.

K-means → 이 제곱 거리를 최소화하는 데이터의 클러스터 배정($c$)을 찾고, 동시에 중심점 위치($\mu$)를 찾는 것.

## 4. 클러스터 개수 K 설정 (Choosing the value of K)

클러스터의 개수를 자동으로 선택하기 위한 몇가지 기법:

- Elbow method: 다양한 $K$ 값에 대해 K-means를 여러 번 실행하고, 클러스터 개수($K$)에 따른 비용 함수 혹은 왜곡 함수 $J$를 그래프로 그린 후 k값이 증가함에 따라 감소속도가 급격하게 빨라지다가 갑자기 완만해지는 꺽임 지점을 클러스터 개수로 채택하는 방법
  → 대부분 현실의 데이터는 그냥 부드럽고 완만하게 감소속도가 떨어지는 경우가 대부분이라 잘 쓰이지 않는다 (학술적/수학적 접근)
- Clustering 결과가 사용될 '후속 목적(Downstream purpose)'에서 얼마나 잘 작동하는지를 기준으로 K-means를 평가: 머신러닝 알고리즘 스스로는 해당 데이터셋에서 몇개의 클러스터가 최적이고 정답인지 알 수 없기 때문에 해당 데이터셋을 사용할 향후 목적과 관점에 따라서 k를 설정 (실무 표준 접근)

### <지역 최소값 문제와 Random Initialization>

K-means의 각 단계는 각각의 변수에 대해 비용 함수 J를 최소로 만드는 방향으로 업데이트하도록 설계되어 있기 때문에, 매 반복마다 비용 함수는 감소하거나 그대로 유지될 뿐 증가하지 않는다.

K-means는 비용 함수가 감소하는 방향으로만 이동하기 때문에, 어떤 초기값으로 중심점을 시작하는지에 따라서 전역 최소값(Global Minimum)이 아닌 지역 최소값(Local Minimum)에 수렴할 수 있다는 문제 존재.

→ 이를 해결하기 위해서 서로 다른 Random Initialization을 통해 K-means를 여러번 실행하고, 각 실행 결과의 비용함수를 계산한 뒤 가장 작은 값을 갖는 결과를 최종 클러스터링으로 선택한다 (일반적으로 50~1000회 정도 반복해서 실행, 한 번만 실행하는 것보다 훨씬 좋은 결과 얻음).

## 5. 이상 탐지 (Anomaly Detection)

이상 탐지: 평범하고 정상적인 데이터에서 새로운 데이터가 주어졌을 때, 기존의 정상 데이터 분포에 속하는지 아니면 동떨어져 있는지 확률적으로 계산하여 분류하는 것.

이상탐지를 수행하는 가장 일반적인 방법으로 Density estimation(밀도 추정)이 있다.

### <밀도 추정 (Density estimation)>

과거 데이터들을 바탕으로 데이터가 어디에 많이 모여있는지에 대한 확률 지도를 그린다. 데이터가 많이 모여 있을 수록(밀도가 높을수록) 정상임을 높은 확률로, 밀도가 낮을수록 낮은 확률로 계산한다.

새로운 데이터 (x)를 입력 받으면, 만들어둔 확률 지도에 대입하여 확률 p(x)을 계산한 후, 우리가 정한 임계값(epsilon 또는 기준치)보다 낮으면 anomaly로 판별하는 구조.

---

## 6. 가우시안 분포 (Gaussian / Normal Distribution)

Density estimation에서 확률 밀도를 추정하는 방법.

$\mathcal{N}(\mu, \sigma^2)$: 가우시안 분포는 mu(평균)과 sigma(표준편차)만 안다면 완벽하게 그릴 수 있다. 평균은 곡선의 정중앙 위치를 결정하고 표준편차는 곡선의 너비를 결정한다.

Gaussian 기반 Anomaly Detection은 주어진 데이터로부터 각 Feature의 평균(μ)과 분산(σ²)을 추정한 뒤, 이를 이용해 해당 Feature를 가장 잘 설명하는 Gaussian Distribution(정규분포) 모델을 만든다. 이후 이 모델을 사용하여 새로운 데이터가 정상 데이터일 확률을 계산한다.

### <평균과 분산 계산>

$\mu$를 계산하는 방법: 모든 훈련 데이터 예제의 평균 내기.

$$\mu = \frac{1}{m} \sum_{i=1}^{m} x^{(i)}$$

$\sigma^2$를 계산하는 방법: 각각의 훈련 데이터 예제와 평균의 차이(편차)를 제곱해서 평균 내기.

$$\sigma^2 = \frac{1}{m} \sum_{i=1}^{m} (x^{(i)} - \mu)^2$$

### <가우시안 분포를 이용한 이상탐지의 작동 원리>

특정 데이터셋이 주어졌을 때, 각 데이터가 가지는 특성들에($x_1, x_2 \sim x_n$) 대하여 가우시안 분포를 이용해 각 특성들이 정상 범주에 있을 확률을($P(x_1)$) 각각 구하고 모두 곱해서 "최종적으로 해당 데이터가 정상적인 확률 $P(X)$"를 구한다.

→ 각 특성이 서로 독립이라고 가정하고 데이터의 정상 확률을 구한다.

### <이상탐지 시스템을 구축하는 방법>

1. anomaly를 가장 잘 나타내고 판별할 수 있을 특징/특성들을 고르고, 데이터셋에 있는 각각의 특성에 대해서 평균과 분산을 구한다.
2. 새로운 예제가 주어졌을 때, 새로운 예제의 각 특성값들에 가우시안 분포 공식을 적용해서 개별 확률 $P(x_n)$을 구하고, 그 확률을 모두 곱해 최종 확률인 $P(X)$를 구한다.
3. $P(X) < \epsilon$ 이면 Anomaly(이상), $P(X) > \epsilon$ 이면 정상으로 판단한다.

특성이 여러개일 때, 대부분이 완벽하게 정상이어도 단 1개의 특성이 비정상적으로 높거나 낮으면 그 특성의 확률 $p(x_j)$가 0에 가까워진다.

## 7. 이상탐지 시스템을 평가하고 개선하는 과정

모델을 만드는 과정에서 특정 특성의 수정, 변형이나 입실론 같은 파라미터 값을 조정한 결과들을 객관적으로 비교할 수 있는 평가지표를 만들기 위해, 훈련 데이터셋, 검증 데이터셋을 사용한다.

훈련 데이터셋은 모델이 정상 상태의 분포를 학습하기 위한 것이기에 거의 모든 데이터가 정상이라고 가정하며 레이블이 없는 데이터들로 구성하는 반면에, 검증 데이터셋은 모델의 평가를 위해서 정상 데이터뿐만 아니라 실제 Anomaly 데이터가 반드시 포함되어 있어야한다.

→ 교차검증(CV) 세트를 이용해 훈련시킨 모델이 실제 Anomaly를 얼마나 잘하는지 측정하고, 정상데이터에 대해서도 얼마나 정확한지 측정해서 최적의 입실론 값을 결정한다.

## 8. 이상 탐지 vs 지도학습 (Anomaly detection vs Supervised learning)

Anomaly detection은 Anomaly의 종류가 아주 다양하고, 미래에 발생할 이상(Anomaly)이 현재까지 관측한 이상과 매우 다른 새로운 형태일 가능성이 클 때 사용한다 → 정상 데이터의 분포(패턴과 특징)를 학습한 뒤, 정상 분포에서 크게 벗어나는 데이터를 이상으로 판단하기에 (= 정상이 어떤 모습인가?를 학습).

Supervised learning은 미래에 발생할 이상을 대표할 수 있을 정도의 이상 데이터가 충분히 존재하고, 미래의 이상이 학습 데이터의 이상과 비슷한 특징이나 패턴을 가질 것으로 예상될 때 사용한다 → 정상과 Anomaly 데이터를 구분하는 경계를 학습시키는 것이기에 (= 학습데이터에 있는 Anomaly의 종류를 기반으로 일반화 하는 것).

→ 알고리즘의 선택은 데이터셋의 양과 구성도 중요하지만, 무엇보다 미래에 발생할 이상이 기존 이상과 유사한지, 아니면 새로운 형태일 가능성이 큰지와 같은 문제의 성격을 우선적으로 고려하여 결정해야 한다.

## 9. 이상 탐지에서의 특성 공학 (Feature Engineering in Anomaly detection)

지도학습에서는 라벨이 있는 데이터를 이용해 학습하므로, 모델이 어떤 특성이 예측에 중요한지, 또는 중요하지 않은지를 오차를 통해 학습 과정에서 판단할 수 있다. 반면 이상탐지는 라벨이 없는 정상 데이터를 기반으로 학습하기 때문에, 어떤 특성이 이상을 구분하는 데 중요한지 직접 알 수 없어, 특성 선택과 특성 공학이 지도학습보다 더욱 중요하다.

- 각 Feature의 분포를 가능한 Gaussian Distribution에 가깝게 변환한다: Gaussian 기반 이상 탐지에선 각 feature의 분포가 정규 분포를 따른다고 가정하여 확률을 계산하는데, 실제 데이터는 한쪽으로 치우친 분포를 가지는 경우가 많기에, 정규분포에 가깝게 변환하면 정상 확률을 더 정확하게 추정할 수 있어 성능을 향상 시킬 수 있다.
- 이상 탐지를 위한 Error analysis 과정 수행: Anomaly로 판별하는데 실패한 예제를 확인해보고, 해당 이상을 정상 데이터와 더 잘 구분할 수 있는 새로운 Feature를 추가하거나 기존 Feature를 개선한다.
